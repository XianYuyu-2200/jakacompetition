# 基础组输入与失败中止回归（2026-11-14）

本次补充全排列软件回归，并修复输入异常与末端反馈丢失时的处理。没有连接真机，没有替换用户姿态配置。

## 修复项

1. 二维码图像缺失或损坏时返回解码失败；只解码 QR 类型。一帧解码出不同载荷时拒绝选择任意首码；同载荷重复出现允许使用。非 UTF-8 载荷拒绝。载荷文本仍由原有排列校验处理，既有前缀、大小写和空白兼容规则不变。
2. 固定姿态每个阶段结束后必须取得三个有限的 TCP 坐标。此前异常会被吞掉、继续保留上一阶段 TCP；现在记录 `last_failure=feedback` 并停止本轮，不再使用旧坐标继续抓取或释放。这不等同于 TF 时间戳新鲜度检测，也不替代真实设备安全联锁。
3. 判分器拒绝非对象 JSON、缺失坐标、错误长度、非数值和非有限数值。此前 NaN 可绕过抓取距离的 `d > tolerance` 比较；现在在修改持有状态或计分前拒绝。有效事件原有几何容差和计分规则不变。
