# 工作台界面改版与验收（2026-11-14）

## 背景与约束

原生 PyQt5 工作台在同一页显示环境设置、固定姿态、流程按钮、环境检查、Gazebo、相机和日志。
1366×768 的离屏截图中，姿态区与下方操作区出现挤压和重叠。因此本次优先调整信息层级，而不是继续缩小字体。

本次仅调整工作台呈现与错误信息的入口，不改抓取算法、比赛规则、ROS 服务协议、用户姿态配置或进程归属。
Gazebo 保留原生 X11 嵌入方式；相机仍复用同一仿真启动链路，不增加独立启动按钮。Wayland 和真机约束不变。

结合 skill 的 `references/pro-rules.md` 与 `references/quick-reference.md` 中的可访问性、焦点、状态反馈、字体和布局规则，保留原生控件并实施以下结构。
没有引入网页运行时、网络字体、图片资源或新的 Python 运行依赖。

## 结构与交互

- 左侧导航：练习控制台、我的程序、运行记录、入门指南；较窄窗口使用短导航文字。
- 控制台左侧：Gazebo 和腕部相机持续显示；普通屏幕上下排布，宽屏左右排布，可拖动分隔条调整比例。
- 控制台右侧：练习流程、姿态调参、环境设置三个标签页，各自垂直滚动，不再把所有表单叠在一页。
- 练习流程按准备环境、获取顺序、执行抓取排列。示例姿态加载仍须确认、仍保留备份。
- 六关节输入改为两列三组，保留弧度单位、工位、阶段、记录、读取、移动和路点功能。
- 本轮状态与「停止本轮」固定在标签区下方，不随参数表单滚走。此按钮仍是仿真软件停止，不是真机急停。
- 日志默认收起；右下角展开。启动异常会展开日志，启动前自检失败会切换到环境设置。
- 深蓝导航、浅灰底、白色卡片、蓝色主操作、红色停止；主题集中在 `workbench/theme.py`。
- 按钮最小高度为 44 个逻辑像素乘用户缩放，保留既有 1.0–1.75 字体缩放和可见键盘焦点。
- 选项与关节输入有可访问名称；主要文字、次要文字、主按钮和危险文字的语义颜色组合纳入 4.5:1 对比度测试。
- 用户程序页面的操作区与预览可滚动，避免大字体下顶端说明和按钮挤压代码区域。

## 验证方法与边界

新增 `workbench/test/test_ui_layout.py`，仅使用临时数据目录和 `demo=True`，不启动 ROS、Gazebo 或真实机械臂。
检查窗口组合：960×620、1024×768、1366×768、1920×1080（1.0 倍），以及 1366×768、1920×1080（1.75 倍）。
检查标签页无水平裁切、关节输入不重叠、表单按钮可滚动到达、停止按钮常驻、相机和 Gazebo 容器同时可见、导航与日志开关、缺失依赖的定位提示。
使用合成 JPEG 检查相机解码、宽高比、缩放和切换标签后继续显示；该测试不证明真实相机或仿真已启动。

截图存放于 `verification/screenshots/20261114-ui-refresh/`，全部标注为演示模式。
机器可读的回归结果存放于 `verification/results/20261114-ui-refresh.json`。

本次没有进行干净学生虚拟机安装、实际 Gazebo/X11 重挂验收、Wayland 验收或真实设备验收。
不声明通过手机布局、全局暗色主题或读屏器实机验收；这些不属于本次 Ubuntu 桌面改版范围。
