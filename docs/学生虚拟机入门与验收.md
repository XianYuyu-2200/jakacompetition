# 学生虚拟机入门与验收

本练习只操作虚拟机械臂。不要连接真实机械臂、相机或夹爪，不要启用 USB 设备透传。当前版本需要教师先完成虚拟机制作与跨电脑导入验收。

## 第一课：运行官方基础程序

1. 校验教师给出的镜像文件哈希，按教师指定的虚拟化软件导入。不要自行升级客体 Ubuntu、ROS 或 Gazebo。
2. 进入 Ubuntu 桌面，点击「基础组学习工作台」。若桌面要求「允许启动」，只对教师提供的快捷方式确认。
3. 在基础组页面点击「环境自检」，再点击「启动环境」。等待就绪，确认六关节角在更新，内置 Gazebo 中能看到机械臂、工位和料盒，内置相机有图像。黑屏或长时间未就绪时先保存日志，不反复启动多套环境。
4. 点击「载入仿真基础姿态」，阅读仅限默认仿真布局的说明并确认。它会备份原配置，载入示例本身不会立即移动机械臂。
5. 点击「生成题目」，记录本轮二维码顺序。注意随机 seed 不是二维码顺序。
6. 点击「运行官方基础模型」，待程序提示等待裁判发令后，点击「发令 / 开始计时」。观察访问工位是否与二维码一致。
7. 完成后查看日志和成绩。程序 6/6、裁判顺序正确和相机正常是分别核对的项目，不能只看总分。

编号固定：1 长方体、2 正方体、3 圆柱体、4 球体、5 三棱柱、6 六棱柱。基础组程序解码生成的二维码 PNG；不是根据相机图像识别这六种物件。

## 第二课：修改并保存一个姿态

先停止本轮，等待程序结束。不要在程序运行时同时手动移动。

1. 选工位 1，选择「预抓取（编号）」。确认输入框单位是 rad，不是角度。
2. 小幅修改一个关节，点击「移动到输入姿态」。规划失败时看日志，不要反复增大角度强行尝试；保持碰撞检查。
3. 等运动结束，点击「读取当前关节角」，再点击「记录此姿态」。记录的是读取到的关节角，不是仅凭画面猜测的位置。
4. 记下界面显示的配置路径和六个数值。关闭环境、关闭工作台，再打开，选择同一工位与阶段，核对保存值仍然存在。
5. 恢复原值或通过「载入仿真基础姿态」恢复官方示例。导入会备份，但不要未经检查就删除备份文件。

本课主要检查修改与持久化；任意改动姿态并不保证后续抓取还能完成。

## 第三课：从空配置记录六工位

为避免覆盖第一课的数据，关闭原工作台后，在项目目录使用独立练习目录启动：

```bash
bash setup/run-workbench.sh --data-dir "$HOME/jaka-practice-empty"
```

- 对六个工位分别记录预抓取、抓取、抬升，共 18 个姿态。
- 对料盒记录投放前、投放、退出，共 3 个姿态。
- 需要绕行时选相应阶段，用「追加阶段前路点」按执行顺序记录；「抓取后转场路点（编号）」在该工位抬升后执行。
- 每次只调整一个阶段，等待运动结束再读取并保存。手工输入的关节值不等于实际到达值。
- 配置不完整时，应看到缺失信息；不得将回退策略执行成功当作自己的固定姿态已经完成。
- 完整录入后先检查配置和逐点规划，再回放整轮。逐点规划通过不证明点间轨迹可执行。

官方示例可供比较和恢复，但直接导入示例不算完成「从空配置示教」练习。仿真录入的数据不是真机标定结果。

## 第四课：停止与恢复

运行途中点击「停止本轮」，确认程序停止，不自动重试下一工位。夹爪或工件状态可能尚未复位；按界面提示检查后执行「重置场景」，再生成题目、运行基础模型并发令。状态异常时关闭本工作台启动的环境后重开。

不要使用网上复制的全局 `pkill`/`killall` 命令清理，也不要把「停止本轮」当作真实机械臂的安全急停。

## 验收提交

向教师提交：宿主机配置、虚拟机配置、预检 JSON、日志和成绩目录、内置 Gazebo/相机截图、姿态重启前后数值、一次停止/恢复记录。教师要求时断开虚拟机网络，再重复启动与基础程序流程，验证是否仍需下载资源。

黑屏、卡顿、非零退出、错误顺序和缺失姿态都应如实记录。不修改 ROS/Gazebo 版本、图形版本覆盖变量或碰撞设置来隐藏失败。
