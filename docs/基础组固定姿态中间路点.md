# 基础组固定姿态中间路点（仿真）

六号工位在完整仿真试跑中出现夹爪与工件碰撞。新增中间路点用于表达经人工调试的路径，不保证找到无碰撞路径，也不允许关闭碰撞检查。

在工作台选择工位和姿态阶段，调整或读取当前六个关节角，点击“追加阶段前路点”。可多次追加，执行时按录入顺序先经过这些路点，再移动到该阶段的目标姿态。选择料盒阶段时，路点作用于所有工位的对应投放阶段。状态文字显示路点数量，鼠标悬停可查看依次记录的关节角；“清空阶段前路点”需确认，清空该工位或料盒所选阶段的全部路点。配置写入工作台自己的仿真配置，不改仓库模板。

抓取后需按工位设置不同的转场路径时，选择“抓取后转场路点（编号）”，依次追加路点；这些点在该工位抬升后、公共料盒阶段之前执行，不影响其他工位。

配置升级到版本 4：每个阶段以 `approach_via_joints` 等列表保存最多 10 个六关节姿态；版本 2 和 3 仍可读取，修改后保存为版本 4，使不支持路点的旧程序拒绝该配置而不是忽略路点。任一中间路点规划或执行失败，立即停止该轮，不自动跳过或回退。逐点自检并不验证连续轨迹或抓放，修改后必须在隔离仿真中对各二维码顺序进行完整回放。已收集的候选姿态仍未验证，不应直接启用。

本功能不完成真机安全联锁或标定，仿真配置不可用于驱动真机；现场运行条件见《真机安全联锁与标定准备》。
